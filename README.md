# ربات تلگرام آموزشی / تستی

این پروژه شامل دو نسخه ساده از ربات تلگرام است که برای آموزش و تست ساخته شده‌اند.

## فایل‌ها

| فایل | کتابخانه | توضیح |
|------|----------|-------|
| `bot.py` | `python-telegram-bot` | نسخه پیشرفته‌تر با پشتیبانی از Business Mode، دکمه‌های اینلاین و پروکسی |
| `Telegram_bot` | `pyTelegramBotAPI` (telebot) | نسخه ساده‌تر آموزشی با دستورات پایه و دکمه‌های خبری |

---

## نسخه ۱: `bot.py` (python-telegram-bot)

### ویژگی‌ها
- منوی اصلی با دکمه‌های اینلاین (درباره ما، تماس، وب‌سایت)
- پاسخ به Callback Query (ویرایش پیام)
- پشتیبانی از **Business Mode** (منشی خودکار)
- امکان استفاده از پروکسی

### نصب وابستگی‌ها
```bash
pip install python-telegram-bot[httpx]
```

### اجرا
```bash
python bot.py
```

### دستورات و دکمه‌ها
| دستور / دکمه | عملکرد |
|--------------|--------|
| `/start` | نمایش منوی اصلی |
| درباره ما | نمایش متن معرفی |
| تماس | نمایش اطلاعات تماس |
| وب‌سایت | لینک مستقیم به سایت |
| بازگشت | برگشت به منوی اصلی |
| پیام در حالت Business | پاسخ خودکار «پیامت رسید...» |

### نکات مهم
- توکن ربات را در متغیر `TOKEN` قرار دهید (فعلاً هاردکد شده).
- در صورت نیاز به پروکسی، آدرس آن را در متغیر `proxy` تنظیم کنید.
- برای Business Mode باید `business_message` و `business_connection` در `allowed_updates` فعال باشند (در کد با `Update.ALL_TYPES` پوشش داده شده).

## نسخه ۲: `Telegram_bot` (telebot)

### ویژگی‌ها
- دستورات ساده: `/start`، `/help`، `/support`، `/news`
- منوی اینلاین برای مشاهده اخبار (ورزشی، عمومی، اقتصادی)

### نصب وابستگی‌ها
```bash
pip install pyTelegramBotAPI
```

### اجرا
```bash
python Telegram_bot
```

### دستورات
| دستور | عملکرد |
|-------|--------|
| `/start` | خوش‌آمدگویی |
| `/help` یا `/support` | نمایش شماره پشتیبانی |
| `/news` | نمایش دکمه‌های لینک اخبار |

---

## نکات امنیتی

- **هرگز** توکن ربات را در کد عمومی قرار ندهید.
- بهتر است توکن را از متغیر محیطی بخوانید:

```python
import os
TOKEN = os.getenv("BOT_TOKEN")
```

- فایل `.env` را به `.gitignore` اضافه کنید.
